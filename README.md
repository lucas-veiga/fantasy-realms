# Fantasy Realms: App of Scoring — Fork

Fork of the [upstream Fantasy Realms scoring app](https://github.com/fantasy-realms/fantasy-realms.github.io). 
Playable at **https://lucasveiga.dev/fantasy-realms-fork/**.

## Bench feature

Cards beyond the active-hand limit sit in a **Bench** section, each showing how many points they would add if swapped in.

- Enabled/disabled state is persisted in the URL (`!` prefix for benched cards).
- Section labels ("Active Hand", "Bench") are fully translated across all 11 supported languages.
